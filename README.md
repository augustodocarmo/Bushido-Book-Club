# Bushido Book Club

Initial landing page for the Bushido Book Club.

## Current scope
- Cinematic Bushidō sales page
- Weekly meeting schedule: Mondays at 19:00 UK time
- First free meeting CTA
- Auto-updating next-meeting date and countdown
- Membership section
- Dedicated FORGE benefit section
- Host section for Augusto do Carmo
- Responsive layout for desktop and mobile

## Design direction
Do not replace the visual language with a generic SaaS template. The intended look is cinematic Japanese editorial: charcoal/black, warm parchment, restrained deep red, large serif typography, generous negative space, subtle kanji, quiet dojo atmosphere and minimal motion.
